This repository is governed by **Scientific Repository Standard v1.0.0**.

The canonical standard defines a research repository as an executable scientific argument organized around:

> **question → hypothesis or objective → method → experiment or evidence → result → interpretation → bounded claim**

For this repository, the most important binding consequences are:

1. **Research before infrastructure.** Work is organized around question → evidence → claim, not feature accumulation.
2. **Anti-bloat.** New abstractions or dependencies require a named experimental or validity purpose.
3. **Honest stage.** The repository remains `Protocol` until empirical work actually begins.
4. **Replication before extension.** Faithful reconstruction must remain distinguishable from any modern IR/geopolitical extension.
5. **Smallest informative step.** Deterministic checks precede strategies; strategies precede evolutionary runs; exploratory calibration precedes frozen replication.
6. **No result laundering.** Debugging or calibration observations cannot become confirmatory evidence.
7. **Evidence traceability.** Later claims must trace through result → analysis → raw evidence → configuration → code commit.
8. **Minimal visuals.** Figures will use the shared restrained scientific visual language only when results exist.
9. **No governance theater.** Tests and process exist only to protect concrete scientific invariants or reproduction paths.
10. **Everything else is subordinate to five questions:** What did we ask? What did we do? What did we observe? What may we conclude? How can someone verify it?
